# Online Contest

This repository contains some of my competitive programming contest solutions and practice problems.

I organize each contest into its own folder and store the problems that I solved during the contest, along with any problems that I later upsolved. The repository serves as a record of my learning journey, contest participation, and progress in competitive programming.

Most solutions are written in C++, and some folders may also contain custom input/output files used for local testing.
## Repository Structure

